# Univ-antv

Бесплатный антивирус с открытым исходным кодом.

Проект распространяется полностью бесплатно: без платных версий, подписок и рекламы.
Антивирус автоматически проверяет наличие обновлений и сам их устанавливает — базы сигнатур и программа остаются актуальными.

> **Статус:** ранняя стадия. Сейчас в репозитории только структура проекта и план функций.

## Возможности (план)

- Проверка файлов и папок по требованию
- Быстрая и полная проверка системы
- Защита в реальном времени
- Автоматическая проверка и установка обновлений программы и баз сигнатур
- Карантин для подозрительных файлов
- Проверка ссылок и загрузок
- Планировщик проверок
- Журнал событий и отчёты
- Исключения (файлы, папки, процессы)

Подробный план по этапам — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Установка

Готовых сборок пока нет. Для запуска из исходников нужен Python 3.10 или новее:

```bash
git clone https://github.com/Zaxar1231/Univ-antv.git
cd Univ-antv
python -m pip install -e ".[dev]"
```

## Использование

```bash
python -m antv --version
python -m antv --help
```

## Разработка

Запуск тестов:

```bash
python -m pytest
```

Структура проекта:

```text
Univ-antv/
├── src/antv/          # исходный код пакета
│   ├── __init__.py    # версия и метаданные
│   └── __main__.py    # точка входа: python -m antv
├── tests/             # тесты
├── docs/              # документация и план развития
├── pyproject.toml     # метаданные и зависимости сборки
├── CHANGELOG.md       # история изменений
├── CONTRIBUTING.md    # как вносить вклад
└── LICENSE            # лицензия MIT
```
