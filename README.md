# Univ-antv

Бесплатный антивирус с открытым исходным кодом.

Проект распространяется полностью бесплатно: без платных версий, подписок и рекламы.
Проверка сигнатур выполняется движком [ClamAV](https://www.clamav.net), базы обновляются автоматически.

> **Статус:** ранняя разработка. Работают проверка файлов, фоновая проверка, проверка программ перед запуском,
> карантин и удаление программ в Windows. Защиты в реальном времени и графического интерфейса пока нет.

## Возможности

- **Проверка файлов и папок** — `antv scan` (с карантином для заражённых файлов)
- **Фоновая проверка** — `antv watch` следит за новыми и изменёнными файлами в выбранных папках
- **Проверка перед запуском** — `antv run` запускает программу только если угроз не найдено
- **Карантин** — заражённые файлы изолируются и могут быть восстановлены
- **Обновление баз** — `antv update`
- **Полное удаление программ (Windows)** — `antv uninstall` запускает тихое удаление и очищает остатки
  (папки, ярлыки, ключи реестра) только после подтверждения

Подробный план — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Требования

- Python 3.10 или новее
- [ClamAV](https://www.clamav.net) с утилитами `clamscan` и `freshclam` в `PATH`
  или в папке, указанной в переменной `ANTV_CLAMAV_DIR`

## Установка

```bash
git clone https://github.com/Zaxar1231/Univ-antv.git
cd Univ-antv
python -m pip install -e ".[dev]"
```

Первый запуск баз:

```bash
antv update
```

## Использование

```bash
# проверить папку, заражённые файлы — в карантин
antv scan ~/Downloads --quarantine

# фоновая проверка каждые 5 минут
antv watch ~/Downloads ~/Desktop --interval 300 --quarantine

# запустить программу, предварительно проверив её
antv run ./tool.exe --help

# карантин
antv quarantine list
antv quarantine restore <id>
antv quarantine delete <id>

# Windows: удаление программы вместе с остатками
antv programs
antv uninstall "Example Tool"                           # только деинсталлятор и показ остатков
antv uninstall "Example Tool" --delete-leftovers --yes  # с удалением остатков
```

Коды возврата `scan`: `0` — угроз нет, `1` — найдены угрозы, `2` — ошибка.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `ANTV_CLAMAV_DIR` | папка с `clamscan` и `freshclam`, если их нет в `PATH` |
| `ANTV_DATABASE_DIR` | папка с базами ClamAV вместо стандартной |
| `ANTV_QUARANTINE_DIR` | папка карантина; по умолчанию `%ProgramData%\antv\quarantine` в Windows и `~/.antv/quarantine` в остальных системах |

## Ограничения

- Проверка перед запуском работает по команде `antv run`. Перехват любого запуска в системе
  (как у антивирусов с драйвером) пока не реализован.
- Каждый вызов `clamscan` загружает базы заново, что занимает секунды. Для частой фоновой проверки
  лучше использовать `clamd`; это запланировано в роадмапе.
- Удаление программ работает только в Windows. Остатки ищутся по точному совпадению имени,
  поэтому часть следов может остаться.

## Разработка

```bash
python -m pytest
```

Тесты с движком ClamAV используют базы из `ANTV_DATABASE_DIR`. Без них они пропускаются.

Структура проекта:

```text
Univ-antv/
├── src/antv/
│   ├── cli.py            # команды командной строки
│   ├── clam.py           # обёртка над clamscan и freshclam
│   ├── scanner.py        # сбор файлов и проверка
│   ├── background.py     # фоновая проверка изменений
│   ├── executables.py    # проверка программ перед запуском
│   ├── quarantine.py     # карантин
│   ├── config.py         # пути и переменные окружения
│   └── uninstall/        # удаление программ и остатков (Windows)
├── tests/
├── docs/ROADMAP.md
├── NOTICE                # атрибуция ClamAV и BCUninstaller
├── pyproject.toml
├── CHANGELOG.md
├── CONTRIBUTING.md
└── LICENSE               # MIT
```
