# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.0] — 2026-10-29

Первый релиз: антивирус на Rust с движком ClamAV, сборки для Windows 7 и новее.

### Добавлено

- Интеграция с ClamAV: проверка через `clamscan`, обновление баз через `freshclam`.
- Команды `scan`, `update`, `watch`, `run`, `programs`, `uninstall`, `quarantine`.
- Фоновая проверка новых и изменённых файлов с настраиваемым интервалом.
- Проверка программ перед запуском: отказ при угрозе, при ошибке проверки или если файл не похож на программу.
- Карантин: перемещение, список, восстановление и удаление.
- Полное удаление программ в Windows: список из реестра, тихое удаление MSI/Inno Setup/NSIS, поиск и очистка остатков.
- Сборки `.exe` для Windows 7 и новее: 64-битная и 32-битная. Собираются Rust 1.77.2 через `scripts/build-windows.sh`; CRT линкуется статически, отдельные библиотеки не нужны.
- Тесты: модульные и сквозные, включая проверку тестовым вирусом EICAR на реальном ClamAV.
- Файл NOTICE с атрибуцией ClamAV и BCUninstaller.
- Структура репозитория, лицензия MIT, план развития в `docs/ROADMAP.md`.

### Изменено

- Проект переписан на Rust. Команды и формат карантина сохранены; сборка через `cargo build --release`.
- Первая версия была на Python; её код удалён, история в git сохранена.
