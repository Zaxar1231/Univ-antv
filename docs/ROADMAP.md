# План развития

Функции разбиты на этапы. Порядок можно менять по мере развития проекта.

## Этап 1. Основа

- [x] Структура репозитория, лицензия MIT, точка входа `python -m antv`
- [x] Интеграция с ClamAV: проверка файлов через `clamscan`, обновление баз через `freshclam`
- [x] Сканирование отдельных файлов и папок (`antv scan`)
- [x] Карантин: перемещение, список, восстановление, удаление (`antv quarantine`)
- [ ] Журналирование событий в файл

## Этап 2. Защита

- [x] Фоновая проверка новых и изменённых файлов в выбранных папках (`antv watch`)
- [x] Проверка программ перед запуском (`antv run`), в том числе скриптов и файлов с заголовком ELF/PE/Mach-O
- [ ] Защита в реальном времени при запуске любых программ (нужен драйвер или перехват процессов)
- [ ] Быстрая и полная проверка системы
- [ ] Исключения (файлы, папки, процессы)
- [ ] Работа через `clamd` для фоновой проверки без повторной загрузки баз

## Этап 3. Удаление программ

- [x] Список установленных программ из реестра Windows (`antv programs`)
- [x] Тихое удаление для MSI, Inno Setup и NSIS (`antv uninstall`)
- [x] Поиск остатков: папки, ярлыки меню «Пуск», ключи реестра
- [x] Удаление остатков только с подтверждением (`--delete-leftovers --yes`) и только внутри известных папок
- [ ] Список программ с интерфейсом и пакетным удалением
- [ ] Очистка остатков для программ из Microsoft Store

## Этап 4. Обновления

- [x] Обновление баз сигнатур ClamAV (`antv update`)
- [ ] Автоматическая проверка новых версий программы
- [ ] Автоматическая установка обновлений программы
- [ ] Откат к предыдущей версии базы при ошибке

## Этап 5. Дополнительные функции

- [ ] Планировщик проверок
- [ ] Проверка ссылок и загрузок
- [ ] Отчёты о проверках
- [ ] Графический интерфейс

## Принципы

- **Бесплатность.** Все функции доступны без оплаты, подписок и рекламы.
- **Открытый код.** Любой может проверить, что делает программа.
- **Безопасное удаление.** Остатки удаляются только после подтверждения и только внутри известных папок.
