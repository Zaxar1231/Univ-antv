# План развития

Функции разбиты на этапы. Порядок можно менять по мере развития проекта.

## Этап 1. Основа

- [x] Структура репозитория, лицензия MIT, точка входа `python -m antv`
- [ ] Загрузка и проверка базы сигнатур
- [ ] Сканирование отдельных файлов и папок
- [ ] Журналирование событий

## Этап 2. Защита

- [ ] Быстрая и полная проверка системы
- [ ] Защита в реальном времени
- [ ] Карантин: изоляция, восстановление, удаление
- [ ] Исключения (файлы, папки, процессы)

## Этап 3. Обновления

- [ ] Автоматическая проверка новых версий программы
- [ ] Автоматическая загрузка и установка обновлений баз сигнатур
- [ ] Проверка подписи обновлений перед установкой
- [ ] Откат к предыдущей версии базы при ошибке

## Этап 4. Дополнительные функции

- [ ] Планировщик проверок
- [ ] Проверка ссылок и загрузок
- [ ] Отчёты о проверках
- [ ] Графический интерфейс

## Принципы

- **Бесплатность.** Все функции доступны без оплаты, подписок и рекламы.
- **Открытый код.** Любой может проверить, что делает программа.
- **Безопасность обновлений.** Программа не устанавливает обновления, подпись которых не проверена.
