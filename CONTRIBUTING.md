# Как вносить вклад

Спасибо за интерес к проекту! Ниже — базовые правила.

## Подготовка окружения

```bash
python -m pip install -e ".[dev]"
python -m pytest
```

## Ветки и коммиты

- Работайте в отдельной ветке, не в `main`.
- Коммиты делайте небольшими и с понятным сообщением в повелительном наклонении:
  `Add quarantine restore command`, `Fix update checksum check`.

## Перед отправкой изменений

- Тесты проходят: `python -m pytest`.
- Новая функция сопровождается тестами.
- Запись добавлена в `CHANGELOG.md` в раздел `Unreleased`.
- Если функция есть в плане, отметьте её в `docs/ROADMAP.md`.

## Безопасность

Если нашли уязвимость, не открывайте публичное обсуждение. Опишите проблему в приватном сообщении мейнтейнеру.
